## 1. 台股市場特性分析

### 1.1 市場結構特徵

| 維度 | 台股（TWSE/TPEx） | 對策略設計的影響 |
|------|:---:|------|
| **上市公司數** | TWSE ~1,000 + TPEx ~830 = ~1,830 檔 | 流動性篩選後可投資宇宙約 500-700 檔 |
| **總市值** | >NT$70-80兆（~US$2.2-2.5兆） | 全球前十大股市，流動性充足 |
| **TSMC 集中度** | 單一個股占 TWSE 市值 ~35-42% | 用 0050/加權指數做 Regime 判斷會被 TSMC 綁架，需用市場寬度（Breadth）修正 |
| **電子權重** | 半導體+電子占每日成交值 65-75% | 必須設板塊集中度上限（sector cap），否則最佳化器會把 80-90% 配到半導體 beta |
| **散戶比例** | 占成交值 ~50-55%（歷史曾達 60-70%） | 短線過度反應頻繁，均值回歸效應在台股顯著強於美股 |
| **外資比例** | 占成交值 ~30-35%，持股市值 >40% | 主導大盤趨勢與權值股定價；MSCI 季度調整造成流動性驟增 |
| **投信比例** | 占成交值 ~5-8% | 集中於中小型股 alpha 挖掘，季底作帳效應顯著 |
| **自營商** | 占成交值 ~5-7%（含避險部位） | 權證避險造市產生可預測的 delta 再平衡流量 |

### 1.2 交易規則與微結構

| 規則 | 規格 | 對量化策略的影響 |
|------|------|------|
| **漲跌幅限制** | ±10%（IPO 前五日不設限） | 停板鎖死時無法執行止損，產生跳空風險；磁吸效應影響盤中定價 |
| **交割週期** | T+2（買後第二個營業日扣款） | 資金規劃需跨越重疊再平衡週期 |
| **交易時間** | 09:00-13:30（4.5 小時） | 壓縮的交易窗口導致日內波動率 U 型分布（9:00-9:30 與 13:20-13:30 最活躍） |
| **整股交易** | 1 張 = 1,000 股 | 200K 資金買高價股（如 2330, 2454）只能走零股交易（09:10 盤中零股撮合），增加滑價 |
| **零股交易** | 盤中 5 秒集合競價（2024.12 起） | 允許精確的投資組合再平衡，但流動性低於整股市場 |
| **升降單位** | 價格分級（<10 元: 0.01、10-50: 0.05、50-100: 0.1、100-500: 0.5、500-1000: 1.0、≥1000: 5.0） | 相對價差隨價格階梯跳變（如 49.95→50.00 時價差從 10bps 跳到 20bps） |

### 1.3 交易成本模型

> [!IMPORTANT]
> 台股總來回成本約 45-50 bps，是美股（近零佣金時代）的 30-50 倍。**高週轉策略在台股無法存活**，策略設計必須將成本模型內建於信號產生邏輯中。

```
總來回成本 = 買入手續費 + 賣出手續費 + 證交稅 + 買賣滑價

波段策略（隔夜持有）：
  買：0.1425%（法定，電子下單通常打 2.8-6 折 → 實際 0.04-0.085%）
  賣：0.1425% + 0.3%（證交稅）= 0.4425%
  滑價：~0.10%（雙邊合計）
  合計：~0.49%（49 bps）

日內當沖策略：
  買：0.1425%
  賣：0.1425% + 0.15%（當沖稅率減半，延至 2027.12）= 0.2925%
  滑價：~0.08%
  合計：~0.32%（32 bps）

ETF 策略：
  買：0.1425%
  賣：0.1425% + 0.10%（股票型 ETF 稅率）= 0.2425%
  滑價：~0.04%
  合計：~0.23%（23 bps）

台指期（TX/MTX）：
  雙邊合計：~0.016%（1.6 bps）
```

**tw_stocker 成本模型**（`independent_sim.py` / `event_backtest.py`）：
- 買入：0.1425%
- 賣出：0.4425%（0.1425% + 0.3% 證交稅）
- 滑價：10 bps（保守估計；資金 >1,000 萬或低量日可能失真至 30-50 bps）

## 2. 策略設計（四種市況策略）

基於 tw_stocker 七波 60+ 組消融實驗的實證教訓，以下策略設計遵循三個核心原則：

> [!TIP]
> **原則 1**：簡單因子勝過複雜因子（Momentum×3 + Trend×1 優於任何加入籌碼/量能/殘差動量的版本）  
> **原則 2**：Regime 控制是最重要風控，優於停損停利參數微調  
> **原則 3**：流動性過濾優先於因子優化（Universe 定義比因子精修更決定生死）

### 2.1 策略 A：v8.5 Top-7 動量（牛市核心策略）

**定位**：穩健底倉，捕捉趨勢延續期的動量 alpha。

**適用市況**：大盤站上 60MA 且趨勢向上（Regime 100% 曝險區間），動量因子效果最佳。

#### 選股邏輯

```
Universe = TWSE 全體上市普通股 (~1,085 檔) 中
           20 日平均成交額 Top-60（每日動態篩選）

Score = 3 × PercentileRank(Mom_20d) + 1 × PercentileRank(TrendBias_60MA)

其中：
  Mom_20d    = Close_t / Close_{t-20}     # 20 日動能
  TrendBias  = Close_t / MA60_t           # 60 日均線乖離率

進場條件：
  1. Score ≥ 2.0
  2. Close > 60MA
  3. Regime ≥ 40%（Breadth Regime + Floor 10%）
  4. 開盤跳空 < 1.5 × ATR20
  5. 每日 Top-7 檔（相關係數 >0.8 時替換）
  6. 板塊上限 sector cap 75%
```

#### 進場/出場規則

| 環節 | 規則 |
|------|------|
| **信號時點** | 前日收盤產生信號 |
| **進場方式** | 當日開盤以前日收盤價掛限價單（Open ≤ Limit → 以 Open 成交；Open > Limit → 09:30 撤單） |
| **停利** | Entry + 4.0 × ATR20 |
| **停損** | Entry - 3.0 × ATR20 |
| **時間出場** | 持有 15 個交易日（P0 已由 20 下修） |
| **優先序** | SL > TP > TIME（保守原則） |

#### 資金管理

| 參數 | 值 | 說明 |
|------|:---:|------|
| 單倉比例 | 7% × regime_scale | 7 倉滿倉 ~49% × regime_scale |
| 現金保留 | 20% | 緩衝追繳/突發回檔 |
| 最大持倉 | 7 檔 | 過度分散稀釋 alpha |
| Gap 調整 | <0.5 ATR: 100% / 0.5-1.0: 75% / 1.0-1.5: 50% / ≥1.5: 跳過 | |

#### 風控機制

1. **Regime 漸進式曝險**（最重要風控）：

| 大盤位置 | 曝險比例 |
|----------|:--------:|
| >60MA 且 >20MA | 100% |
| >60MA 且 <20MA | 70% |
| <60MA 且 >20MA | 40% |
| <60MA 且 <20MA | 10%（Floor） |

2. **外部 Portfolio Hardstop**：整體回撤 -8%~-10% → 全平倉 + 暫停 10-15 天
3. **人工 Override**：連續 2 月 vs 0050 月勝率 <50% → 暫停新單 1 月

### 2.2 策略 B：MR20 順勢回檔均值回歸（回檔避震策略）

**定位**：在多頭結構未破壞的前提下承接短線超賣反彈，與 Top-7 動量形成低相關互補。

**適用市況**：大盤仍在 60MA 之上、但短期出現獲利了結式回檔（非趨勢反轉）；在 Regime 40-70% 的震盪盤整期最有價值。

#### 選股邏輯（五大核心條件）

```
Universe = TWSE 全體上市普通股中，有 ≥60 天歷史資料者
           → 從中取 20 日平均成交額 Top-50

五大進場條件（全部通過才產生信號）：
1. 流動性：20 日均額 Top-50
2. 中期多頭：MA20 > MA60 且 Close > MA60（結構未破壞才進場）
3. 已回檔：Close < MA20（短線轉弱）
4. 短線超賣：RSI(5) ≤ 40（Wilder 算法）
5. 止跌確認：Close[t] > Close[t-1]（避免接刀）

Score = 100 - RSI(5)
排序：Score 由高到低 → 成交額由大到小 → 代號由小到大
每日輸出前 7 名
```

#### 與 Top-7 的本質差異

| 維度 | Top-7 動量 | MR20 均值回歸 |
|------|------|------|
| 買入對象 | 創新高的強勢股 | 多頭結構內回檔到超賣的股票 |
| 信號方向 | 追強 | 撿便宜 |
| 最佳表現期 | 強趨勢延續期 | 震盪回檔期 |
| 預期相關性 | — | 與 Top-7 理論低相關（**需實證驗證**） |

#### 進場/出場規則

| 環節 | 規則 |
|------|------|
| **信號時點** | 信號日收盤後產生 |
| **進場方式** | 次日以信號日收盤價掛限價單（Open ≤ Limit → 以 Open 成交） |
| **停利** | Fill_price + 4.0 × ATR20 |
| **停損** | Fill_price - 3.0 × ATR20 |
| **時間出場** | 20 個交易日 |

#### 資金管理

| 參數 | 值（independent_sim 配置） |
|------|:---:|
| 單倉比例 | 45% |
| 最大持倉 | 2 檔 |
| 現金保留 | 20% |

#### 已知問題與改進方向

| 問題 | 現況 | 建議改進 |
|------|------|------|
| RSI 門檻太嚴格 | RSI(5) ≤ 35-40，觸發率低 | 放寬至 RSI(5) ≤ 45 + 引入 Bollinger Band 距離作為替代超賣指標 |
| 止跌確認太嚴格 | 要求 Close[t] > Close[t-1] | 可改為 Close[t] > Low[t]（收盤脫離當日最低即可） |

| 缺乏 Regime 判斷 | 條件 2（MA20>MA60）是內生的熊市保護，但沒有動態曝險控制 | 可沿用 Top-7 的 Breadth Regime 框架，但起算不同 |

> [!NOTE]
> MR20 的進場條件 2（MA20 > MA60 且 Close > MA60）會在真正的空頭市場自動失效（找不到合格候選），因此**不需要額外開關去停用它**。這是策略內生的熊市保護。

### 2.3 策略 C：RSI 反轉動能（熊市/震盪短線策略）— 新設計

**定位**：利用台股散戶過度反應特性的短線均值回歸，3-5 天快速回收資金。

**適用市況**：所有市況皆可運行（但在高波動期/熊市回檔時表現最佳），透過嚴格的進場條件自動調節觸發頻率。

**設計理念**：台股學術研究顯示，1-5 天的短線反轉效應在台股市場顯著強於美股（原因：高散戶比例 + 處置效應 + 隔日沖主力行為模式）。此策略專門捕捉 3-5 天的技術性超賣反彈。

#### 選股邏輯

```
Universe = TWSE 全體上市普通股中
           20 日平均成交額 Top-80（更寬的流動性池以提高觸發率）

### 2.4 策略 D：Regime 動態配權混合策略

**定位**：不是「四選一」，而是依 Regime 分數動態調整策略引擎的資金配置比例。

**核心思想**：基於 tw_stocker 七波消融實驗的關鍵教訓——混合策略的正確做法是**策略級別的資金配置切換**，而非在單一選股引擎內部混入更多因子（Ensemble Floor0.10+Floor0.00 → Sharpe 降至 2.19；SFT → 全部輸 baseline）。

#### Regime 判斷引擎

```

      regime = "STRONG_BULL"     # 曝險 100%
  elif 0050 > MA60 且 (0050 < MA20 或 Breadth < 60%):
      regime = "BULL_PULLBACK"   # 曝險 70%
  elif 0050 < MA60 且 0050 > MA20:
      regime = "BOTTOMING"       # 曝險 40%

Secondary Signal（輔助參考，不做硬 gate）：

  - SOX 費半指數走勢：隔夜 SOX + TSM ADR 方向

```

### 4.4 換倉機制設計

> [!IMPORTANT]
> 換倉機制是 tw_stocker 目前最迫切的結構性改進需求。歷史資料顯示 7 倉滿倉後，系統平均被鎖死 20 天，期間所有更強的新信號全部被撤單（`CANCELLED_NO_CAPACITY`）。

#### 推薦方案：Score-Based Replacement with Rank Buffer（結合 docs/TURNOVER_PLAN.md Step 3）

```
核心邏輯：
  對每個新信號 S_new：
    if 持倉數 < MAX_POSITIONS:
        正常開倉
    elif 持倉數 >= MAX_POSITIONS:
        找持倉中最弱者 P_worst（rank 最大 / 持有天數最長）
        
        # Rank Buffer 規則（避免 whipsaw）：
        if P_worst.day_count >= 12 且 S_new.rank - P_worst.entry_rank <= -1:
            # 持有超過 12 天的弱倉，新信號只要好 1 名就換
            REPLACE(P_worst → S_new)
        elif P_worst.day_count >= 8 且 S_new.rank - P_worst.entry_rank <= -3:
            # 持有超過 8 天的弱倉，新信號要好 3 名才換
            REPLACE(P_worst → S_new)
        elif P_worst.day_count >= 5 且 S_new.rank - P_worst.entry_rank <= -5:
            # 持有超過 5 天的弱倉，新信號要好 5 名才換
            REPLACE(P_worst → S_new)
        else:
            CANCELLED_NO_CAPACITY

成本考量：
  一次 REPLACE 的來回成本 ≈ 0.87%（買+賣+稅+滑價）
  月換手 4 次 ≈ 3.5% 成本拖累
  → 門檻設計需確保 E[α_new] - E[α_held] > 2 × 0.45% + 0.30% = 1.20%
```

### 5.3 Walk-Forward 驗證方法

```
Anchored Walk-Forward（tw_stocker 現行方法）：

  1. 每折 OOS Sharpe（目標 ≥ 0.8）
  2. 正 Sharpe 折數比例（目標 ≥ 75%，即 3/4）

  - 除了單策略 WF，必須跑「合併報酬序列」的 WF
  - 驗證策略間相關性是否在 OOS 期間保持穩定
  - 如果相關性在壓力期飆升 → 分散化效果被高估

### 5.4 Monte Carlo 模擬

```python
# tw_stocker 現行方法（monte_carlo.py）：Equity-Curve Block Bootstrap

方法：
  1. 取完整回測期間的日報酬序列 r_1, r_2, ..., r_T
  2. 隨機抽取 20 日為一 block（保留短期自相關結構）
  3. 拼接成新的合成路徑
  4. 重複 2000 次

輸出分布：
  - 5th percentile（最差 5%）/ 25th / Median / 75th / 95th
  - 主要關注：5% 最差 MDD → 決定最低資金門檻

v8.5 實證結果：
  - 5% 最差 MDD：-24.8%（合理）
  - 但 Top-7 全部同時反轉的極端情境 → 最差 5% MDD 可達 -44.6%

多策略組合 MC：
  - 獨立跑各策略 MC → 合併後計算組合 MDD 分布
  - 驗證分散化是否真的降低了尾部風險
```

### 5.5 Probability of Backtest Overfitting (PBO)

```
PBO via CSCV (Combinatorially Symmetric Cross-Validation)：
  1. 將 T 天歷史切為 S 等份（通常 S=8 或 S=16）
  2. 取 C(S, S/2) 種組合作為 Train/Test 分割
  3. 在每個 Train 上找最佳參數 → 在對應 Test 上評估
  4. 統計「Train 最佳參數在 Test 上表現最差」的比例

解讀：
  PBO = 0.5 → 50% 機率過擬合（隨機）
  PBO ≤ 0.3 → 策略有真實 alpha
  PBO ≥ 0.7 → 高度過擬合

tw_stocker 教訓：
  v8.5 候選集 PBO = 0.94 → 極高過擬合風險
  → 未升級新參數，維持 baseline（正確決策）

注意：walk_forward_nested.py 的 PBO CSCV 實作移除了對稱對
（C(8,4)=70→35），引入偏差，需修正為完整對稱分割
```

## 附錄 B：策略組合的理論基礎

### B.1 Kelly Criterion 與 Position Sizing

```
多資產 Kelly 公式：
  F* = C × Σ^(-1) × (μ - r_f)

其中：
  Σ = 報酬共變異矩陣
  μ = 期望報酬向量
  r_f = 無風險利率
  C = 分數 Kelly 乘數

台股建議：Quarter-Kelly (C = 0.25) 到 Third-Kelly (C = 0.33)
  → 單倉上限 ≤ 20%（5 倉組合）或 ≤ 12.5%（8-10 倉組合）

原因：Full Kelly (C=1) 在參數估計誤差下造成巨大回撤
```

### B.2 ATR-Based Volatility Parity（用於策略間配置，非用於個股）

```
注意：Vol Parity 在個股 position sizing 層面已被消融否決（MDD -56.4%）
但在策略間配置層面仍然是合理的原則：

  策略 i 的配額 ∝ 1 / σ_i（策略的歷史波動率倒數）

例如：
  Top-7 年化波動率 32%、RSI 反轉年化波動率 12%
  → RSI 反轉的配額 = 32/12 = 2.67 倍（但受上限約束）
```

### B.3 Rank Buffer 換倉理論（Hysteresis Rule）

```
理論基礎：
  只有當新候選的預期 alpha 超過交易成本門檻時才值得換倉

  E[α_candidate] - E[α_held] > 2 × Round_Trip_Cost + δ_friction

在台股（Round-Trip Cost ≈ 0.45%）：
  E[Δα] > 2 × 0.45% + 0.30% = 1.20%

實務設計（tw_stocker 推薦）：
  • 進入門檻：Rank ≤ 5（只有 Top-5 才能新進）
  • 保留緩衝：Rank ≤ 20（現持倉只要不跌出 Top-20 就繼續持有）
  • 淘汰門檻：Rank ≥ 21（跌出 Top-20 才被替換）
  
  這個 5→20 的緩衝帶可減少 60-70% 換手率，同時保留 >90% 因子 alpha
```
